🧠 How ALS (Collaborative Filtering) Works

1

Input Matrix

A matrix of Users × Actions with ratings. Most values are empty (sparse matrix).

2

Matrix Factorization

ALS breaks the matrix into 2 smaller matrices — User Factors & Item Factors.

3

Alternating Optimization

Fixes User matrix → solves Item matrix → fixes Item → solves User → repeats until optimal.

4

Predict & Recommend

Reconstructs the full matrix and picks the top-rated unseen actions per user.

Technologies

      
Tech Stack Explained

      
Each technology was chosen for a specific Big Data purpose.

    


    

      

        
🐘

        
Apache Hadoop HDFS

        
Storage Layer

        
Why? Large financial datasets cannot fit on a single machine. HDFS distributes data across multiple nodes with automatic replication (fault tolerant).

      


      

        
⚡

        
Apache Spark

        
Processing Engine

        
Why? Spark processes data 100x faster than Hadoop MapReduce by keeping data in-memory. It also has built-in MLlib for ML model training.

      


      

        
🧠

        
ALS Algorithm

        
ML — Collaborative Filtering

        
Why? ALS handles sparse matrices efficiently. With millions of users and few actions each, the rating matrix is mostly empty — ALS fills the gaps through matrix factorization.

      


      

        
🔬

        
Spark MLlib

        
ML Library

        
Why? MLlib is Spark's built-in machine learning library that is distributed by nature. Training runs in parallel across all cluster nodes automatically.

      

    


    
    

      
📋 Spark Code Flow Explained

      

        

          
1

          

            
Read Data from HDFS

            
// Read CSV from Hadoop HDFS
df = spark.read.csv("hdfs:///finance/data/finance_nba_data.csv",
                    header=True, inferSchema=True)
df.show()

          

        

        

          
2

          

            
Prepare DataFrame

            
// Cast to correct types
df = df.withColumn("userId", col("userId").cast("integer"))
       .withColumn("actionId", col("actionId").cast("integer"))
       .withColumn("rating", col("rating").cast("float"))

          

        

        

          
3

          

            
Train ALS Model

            
// Configure ALS
als = ALS(maxIter=10, regParam=0.1,
          userCol="userId", itemCol="actionId", ratingCol="rating",
          coldStartStrategy="drop")

model = als.fit(df)  // Train!

          

        

        

          
4

          

            
Generate Recommendations

            
// Top 3 recommendations per user
recommendations = model.recommendForAllUsers(3)
recommendations.write.json("hdfs:///finance/output/recommendations")
